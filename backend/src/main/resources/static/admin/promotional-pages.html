Promotional Pages

Create Promotional Page

Title and Public address are required. All other fields are optional.

Basic information

A short description displayed with the page and when its link is shared. Up to 255 characters.

/p/

This becomes the public link used to open and share the page. Enter only the part after /p/, not a full web address. Use letters A–Z, numbers, and single hyphens between words (up to 120 characters). Example: october-event-2026.

Page content

Detailed information displayed when someone opens the promotional page. Plain text, up to 10,000 characters.

No promotional image selected.

Choose a PNG, JPEG, WEBP, or GIF image, up to 5 MB. A selected image is uploaded when you save. Removing a current image takes effect immediately.

Publishing

Published pages can be opened using their public link until they expire.

Expiration (optional)

Leave both limits blank for no expiration. If you set both, the first condition reached expires the page.

Choose a date and time in your local time zone. Leave blank if this page should not expire on a specific date.

The page expires after this many different visitors have viewed it. Repeat visits by the same visitor do not count again. Leave blank for no visitor limit.

Optional. Enter a Tentacles path beginning with "/", such as /admin/ or /survey.html?id=123. External web addresses (including full https:// URLs) are not supported. Leave blank to show Not Found after expiration.
